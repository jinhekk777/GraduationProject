# 项目概要

## 项目定位

`GraduationProject` 是一套面向公众的中国传统榫卯结构 VR 科普体验。项目属于产品设计方向，不以真实材料力学仿真或专业木工技能培训为目标。

## 平台与用户

- 引擎：Unreal Engine 5.8
- 运行平台：基于 OpenXR 的 Windows PC VR
- 头显：Quest 3，通过 PC 串流使用
- 目标用户：缺少专业木工知识的普通参观者和学生

## 教学目标

用户完成体验后应能够：

1. 识别具有代表性的榫卯及其主要构件。
2. 理解榫卯的空间结构、连接方向和基本约束原理。
3. 在按需提示支持下完成装配，并至少独立完成一种榫卯挑战。
4. 将单个榫卯与家具或建筑中的实际应用联系起来。

## 目标体验

- 使用一个完整的虚拟木作坊场景。
- 产品结构采用“学艺、馆藏、学习成果”三个核心模块，不包含玩家社区或 UGC 切磋功能。
- 包含简短的 VR 新手引导。
- 展示区包含约 10～15 种榫卯。
- 至少完成 3 种深度交互榫卯，时间允许时扩展到 4～5 种。
- 核心学习流程：观察、爆炸拆解、独立挑战、按需提示、结果反馈。
- 至少选择 1 种深度交互榫卯加入“形状推理、预设加工、完成制榫、装配验证”的加工体验，首选直榫。
- 候选实操榫卯：直榫、燕尾榫、粽角榫，以及可选的抱肩榫。

## 范围边界

- 采用受控的混合式装配，不进行完整的木材摩擦、形变或结构力学模拟。
- 优先完成 PC VR，不将 Quest 一体机独立运行作为第一阶段要求。
- AI 用于辅助开发，不要求在最终程序中加入生成式 AI 功能。
- 不以牺牲核心装配体验的质量来增加内容数量。
- 制榫加工采用预设加工区域、步骤验证和模型阶段切换，不实现任意体素切割或运行时布尔破坏。

## 评价方向

- 功能测试和头显实机测试。
- 完成时间、错误次数、提示次数和完成率等任务数据。
- 可用性问卷。
- 简短的知识前测与后测。
