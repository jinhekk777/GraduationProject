# 当前状态

## 当前阶段

直榫与燕尾榫共用的第一版 VR 教学闭环已经完成，准备建立 Git 里程碑并进入直榫制榫原型设计。

## 已确定事项

- UE 5.8 工程已经建立，使用 Epic 的 XR 框架/模板内容。
- OpenXR 已启用。
- 目标设备为通过 PC 串流连接的 Quest 3。
- 已选择 C++ 优先的混合开发架构。
- 已确定产品定位和整体体验方向。
- 直榫资产已准备在 `/Game/Mesh/zhi_sun`，包含独立的榫头和卯眼模型。
- 两个直榫模型使用相同位置、旋转和缩放时可以完整装配，插入轴为榫头局部 Z 轴。
- 直榫已完成“抓取、引导、吸附、反馈、统计和复位”闭环验证。
- 燕尾榫已接入同一装配框架并完成闭环验证，证明当前两构件装配机制可以复用。
- 燕尾榫资产位于 `/Game/Mesh/yanwei_sun`，交互资产位于 `/Game/Assembly/YanWei`。
- 当前教学流程为“选择榫卯、结构观察与爆炸演示、独立挑战、按需提示、结果反馈、重试或切换”。
- 取消独立的引导装配阶段是已确认的产品决策；原引导内容作为独立挑战中的渐进提示使用。
- 借鉴《匠木》的内容组织方式，后续产品采用“学艺、馆藏、学习成果”结构，不实现切磋或 UGC。
- 后续增加受控的制榫加工体验，第一版使用直榫和预设加工步骤，不实现任意实时切割。
